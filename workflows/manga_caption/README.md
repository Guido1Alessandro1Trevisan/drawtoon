# Drawtoon Manga Panel Caption

Haiku-only panel caption workflow.

Input:

```text
s3://drawtoon/datasets/pages/filtered/<chapter>/<page_side>.jpg
s3://drawtoon/datasets/annotations/magi_v3/<chapter>/<page_side>.jsonl
```

Output:

```text
s3://drawtoon/captions/<caption_run>/<chapter>/<page_side>.json
```

Each page worker sends one Bedrock request per panel and stores one page JSON with embedded panel captions. Haiku returns only the caption body. The worker injects the manga prefix afterward so stored captions start like:

```text
Black and White Manga. 20th Century Boys by Naoki Urasawa. 20th Century Boys style. Character 1 ...
```

The prompt references only `Character N` labels, not visual feature descriptions. It asks Haiku for a descriptive 70-90 word caption body ordered around visible subject/action, shot size, camera angle, lighting/contrast, background, and composition. Captions should stay descriptive, not interpretive, and should not mention black-and-white, linework, title, author, or manga style because those are injected by code.

Haiku also classifies each text region as exactly one of:

```text
Speech Bubble
Narration Bubble
Shout Bubble
None
```

`None` means free-floating text, signs, SFX, or any text not inside a speech/narration/shout bubble. Those regions are kept in captions metadata but do not get a training layout mask.

Boxes stay deterministic from MAGI-v3 annotations and are not generated by the model. Training layout masks use a white background and rectangular character boxes. Text regions fill the full bbox blue so the model learns the whole text area; speech and shout types add blue oval/spiky geometry outside the bbox, while narration stays a plain blue rectangle.

Deploy:

```bash
cd /Users/guidotrevisan/Desktop/drawtoon/workflows/manga_caption
sam build
sam deploy \
  --stack-name drawtoon-manga-caption \
  --region us-east-1 \
  --profile lineart2-s3 \
  --capabilities CAPABILITY_IAM \
  --resolve-s3 \
  --parameter-overrides DatasetBucketName=drawtoon
```

Dry run:

```bash
python start.py \
  --stack-name drawtoon-manga-caption \
  --profile lineart2-s3 \
  --dry-run \
  --max-concurrency 400 \
  caption-pages \
  --caption-run haiku45_mangazero_panel_simple_v1 \
  --include-chapter-regex '_mangazero$'
```
