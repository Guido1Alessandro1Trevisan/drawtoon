# download_scraper

Reusable manifest-first downloader for authorized image assets.

The intended data path is:

```text
authorized source/CDN -> AWS Lambda worker -> private S3
```

The local machine only builds manifests, deploys the workflow, and monitors
status.

## Layout

```text
workflows/download_scraper/
  adapters/
    base.py
    dc_browser_manifest.py
  aws/
    src/worker.py
    scripts/deploy.py
    scripts/status.py
    scripts/summarize.py
  config/
    sources.example.json
    filters.example.json
  manifests/
  logs/
```

## Manifest Contract

Every adapter writes JSONL rows like:

```json
{
  "source_type": "official_rights_holder_cdn_manifest",
  "platform": "dc",
  "series_slug": "batman",
  "issue_slug": "issue-000001",
  "page_no": 1,
  "image_url": "https://cdn.example/page.jpg",
  "referer": "https://www.dc.com/...",
  "headers_profile": "dc_browser_session",
  "output_prefix": "datasets/pages/single/dc/batman/issue-000001",
  "metadata": {
    "authorization_ref": "DC-DRAWTOON-CDN-INGEST-2026-05-18"
  }
}
```

Do not store cookies or bearer/session secrets in manifest rows. Store them in
AWS Secrets Manager and pass the secret name at deploy time.

## DC Browser Manifest

For DC-style authorized browser flows, export a HAR from a normal authorized
browser session, then create a manifest from the image requests:

```bash
python3 workflows/download_scraper/adapters/dc_browser_manifest.py \
  --input /path/to/dc-reader.har \
  --output workflows/download_scraper/manifests/dc_issue.jsonl \
  --series-slug batman \
  --issue-slug issue-000001 \
  --authorization-ref DC-DRAWTOON-CDN-INGEST-2026-05-18 \
  --referer https://www.dc.com/ \
  --url-contains dc
```

The adapter extracts browser-loaded image URLs only. It does not guess CDN paths
and does not export cookies.

## Read Free Comics Online Public Issue Pages

For the Marvel/DC authorization
`MARVEL-DC-DRAWTOON-THIRD-PARTY-INGEST-2026-05-18`, build a manifest from the
listed public issue pages:

```bash
python3 workflows/download_scraper/adapters/readfreecomicsonline_manifest.py \
  --sources workflows/download_scraper/config/marvel_dc_rfco_20260518.json \
  --output workflows/download_scraper/manifests/marvel_dc_rfco_20260518.jsonl \
  --report workflows/download_scraper/manifests/marvel_dc_rfco_20260518_report.json
```

The adapter fetches each issue page with normal browser-like headers, extracts
only image URLs present in the rendered page HTML, and stores the issue page URL
as the download `Referer`. Output rows use the existing single-page dataset
shape under `s3://drawtoon/datasets/pages/single/<publisher>_<issue>_comic/`.
It does not guess image paths, export cookies, or use authenticated metadata.

## Session Secret

If the source requires an authenticated browser session, create an AWS Secrets
Manager secret with browser-derived request metadata. Example shape:

```json
{
  "headers": {
    "Cookie": "name=value; ...",
    "User-Agent": "Mozilla/5.0 ..."
  }
}
```

Use only session data generated by the normal authorized browser flow and only
for assets made available during normal rendering.

## Deploy And Start

```bash
python3 workflows/download_scraper/aws/scripts/deploy.py \
  --manifest-path workflows/download_scraper/manifests/dc_issue.jsonl \
  --bucket drawtoon \
  --region us-east-1 \
  --run-id dc_ingest_20260518 \
  --session-secret-name <aws-secret-name> \
  --proxy-mode auto \
  --max-concurrency 300 \
  --reserved-concurrency 350 \
  --start
```

`--proxy-mode` values:

- `direct`: Lambda source fetches use direct AWS egress.
- `proxy`: Lambda source fetches use Decodo env vars.
- `auto`: try direct first, then proxy if configured.

S3 uploads are always direct from Lambda to S3.

## Monitor

```bash
python3 workflows/download_scraper/aws/scripts/status.py \
  --execution-arn '<execution-arn>' \
  --region us-east-1
```

Summarize object counts from a manifest:

```bash
python3 workflows/download_scraper/aws/scripts/summarize.py \
  --manifest-path workflows/download_scraper/manifests/dc_issue.jsonl \
  --bucket drawtoon
```
