You are assigning existing Magi character bounding boxes to visual character labels within one manga/webtoon board sheet.

Input:
- Image 1 is the clean board sheet.
- Image 2 is the same board sheet with Magi overlays.
- The text metadata lists bbox ids and exact coordinates.

Task:
Return only a simple mapping from each bbox id to a direct descriptive character label, or NoCharacter.

Output format:
{
  "sheet_id": "sheet_id_here",
  "bbox_assignments": {
    "bbox1": "red-haired woman in red dress",
    "bbox2": "woman in orange dress",
    "bbox3": "NoCharacter"
  }
}

Rules:
1. Use only the provided bbox ids: bbox1, bbox2, etc.
2. Every bbox id from the input must appear exactly once in bbox_assignments.
3. Do not invent extra bbox ids.
4. Values must be direct labels, not character0/character1 ids.
5. Use concise descriptive labels based on visible traits: "red-haired woman in red dress", "white-haired man in suit", "woman in orange dress", "blond boy", etc.
6. If two boxes show the same visual person, use exactly the same descriptive label string for both boxes.
7. If two boxes show different people, use different descriptive label strings.
8. Return NoCharacter when the box does not actually contain a character/person, is only background/object/panel art, speech bubble/text/tail, or is too ambiguous to identify as a person.
9. Duplicate overlap rule: if two boxes overlap the same person and would receive the same descriptive label, keep only the larger/more complete box as that label and return NoCharacter for the smaller duplicate box.
10. If a smaller box is only a crop inside a larger box of the same person, return NoCharacter for the smaller crop.
11. If overlapping boxes cover different people, keep both and assign different descriptive labels.
12. For silhouettes, backs, tiny partial bodies, hands, or heavily occluded boxes: use a character label only if it clearly depicts a person and can be visually grouped; otherwise use NoCharacter.
13. Do not use Magi source_character_id as identity. It is only detector metadata.
14. Use visual identity: face, hair, clothing, body shape, accessories, panel continuity, and clear speech-tail evidence.
15. Do not merge people only because they are near each other, in the same scene, or have the same Magi label.
16. Do not split the same person only because pose, crop, scale, expression, lighting, or front/back view changes.
17. Do not create a separate character_legend. Put the descriptive label directly in bbox_assignments.
18. Return JSON only. No explanations.
